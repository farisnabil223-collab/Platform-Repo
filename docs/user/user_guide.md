# EduVerse User Guide

This guide helps end-users navigate the EduVerse portal features.

---

## 1. Navigating the Portal

- **My Courses**: Access assigned courses, syllabus outlines, and modules.
- **Grades & Progress**: View current progress metrics, assessments, and attendance logs.
- **Support Tickets**: Open a support case when experiencing portal interface issues.

---

## 2. Privacy Settings
- Access your profile settings to control cookie consents or request right-to-erasure reports under GDPR guidelines.
