## 1. Live Learning Capabilities Roadmap (Sprint 25 Target)

- **Scheduled Live Sessions:** Teacher schedules live classes with specific start time, duration, and course module linkage (`LiveSession` model).
- **WebRTC / Gateway Integration:** Low-latency video streaming integration via Dyte / WebRTC / Cloudflare Stream Live.
- **Interactive Features:** Real-time chat, hand raising, screen sharing, and participant roster.
- **Automated Attendance:** Records student joining/leaving timestamps directly into `AttendanceRecord`.
- **Recording Archive:** Automatically exports finished stream recordings into Cloudflare Stream for asynchronous replay.
