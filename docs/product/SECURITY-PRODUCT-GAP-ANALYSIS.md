## 1. Security & Compliance Product Gaps

- **Multi-Factor Authentication (MFA/TOTP):** Optional TOTP authenticator app support planned for Admin and Teacher accounts.
- **Account Deletion & Data Privacy Export:** Self-service GDPR/CCPA data export endpoints (`GET /api/v1/users/me/export`).
- **Parental Consent Enforcement:** Verification workflow for student accounts created by parents under age 13.
