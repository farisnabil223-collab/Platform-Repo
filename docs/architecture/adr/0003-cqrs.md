# ADR 0003: Command Query Responsibility Segregation (CQRS)

* **Status**: Approved
* **Context**: System performance degrades when read workloads share execution paths with heavy transactional writes.
* **Decision**: Separate read and write pipelines:
  - Commands: Mutate system state (e.g. `save()`).
  - Queries: Fetch read-optimized models (e.g. `getComplianceDashboard()`).
* **Consequences**:
  - Independent scaling of read and write endpoints.
  - Simplified read models.
