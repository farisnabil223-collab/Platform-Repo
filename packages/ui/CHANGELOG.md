# Changelog - @eduverse/ui

All notable changes to the UI Components library will be documented in this file.

## [1.0.0] - 2026-07-28
### Added
- Standardized UI components (Button, Input, Textarea, Checkbox, Radio, Select, Card, Badge, Avatar, Dialog, Modal, Toast, Table, Skeleton, Loading, ErrorBoundary, Breadcrumb, Pagination, Tabs, Accordion, Progress, Notification).
- Functional wrappers (ThemeSwitcher, LanguageSwitcher, ProfileMenu, StatisticCard, SearchBar, CommandPalette).
- Framer Motion custom SVG Area, Line, and Bar charts avoiding React 19 charting collisions.
