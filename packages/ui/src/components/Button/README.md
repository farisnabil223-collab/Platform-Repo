# Button Component

Enterprise-grade button component.

## Properties
- `variant`: 'primary' | 'secondary' | 'outline' | 'ghost'
- `size`: 'sm' | 'md' | 'lg'
- `loading`: boolean (renders a spinner and disables click actions)

## Accessibility
- Implements `aria-busy` when loading.
- Implements `aria-disabled` matching states.
- Fully supports keyboard activation.
