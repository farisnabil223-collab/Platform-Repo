# Changelog - @eduverse/design-tokens

All notable changes to the Design Tokens system will be documented in this file.

## [1.0.0] - 2026-07-28
### Added
- Standardized color system with tailorable light and dark theme HSL mappings.
- Custom typography layout sizing grid, shadows, border radius, and motion duration states.
- Reusable preset extensions for Tailwind CSS presets.
